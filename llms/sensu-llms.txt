# Sensu

> Sensu (Sensu by Sumo Logic) is an observability pipeline that delivers monitoring as code across multi-cloud and hybrid environments. Sensu Go exposes a backend REST API (core/v2 plus enterprise APIs) and the sensuctl CLI for managing checks, events, entities, filters, handlers, mutators, pipelines, assets, silences, RBAC, and users, integrating with Nagios, StatsD, Telegraf, and Prometheus from bare metal to Kubernetes.

## APIs

- [Sensu Go Backend REST API](https://docs.sensu.io/sensu-go/latest/api/): Resource-oriented JSON REST API under /api/core/v2/namespaces/<namespace>; JWT access tokens or persistent API keys; limit/continue pagination; labelSelector/fieldSelector filtering; Etag conditional requests.
